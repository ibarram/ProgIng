Detailed Description

Genera n números aleatorios en [min,max] y calcula la media.

Uso: ./Ejemplo040 n min max

Donde:

  • n es el número de muestras (1 <= n <= N).
  • min y max definen el intervalo; si vienen invertidos, el programa los intercambia.

El programa: 1) Genera n valores: x[i] = ((max-min)*rand())/RAND_MAX + min 2) Imprime cada valor. 3) Calcula e imprime la media.
