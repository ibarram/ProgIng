Detailed Description

Ordenamiento por conteo (Counting Sort) para enteros en el rango [min, max].

Este programa genera un arreglo de n enteros aleatorios en el rango [min, max], usa un histograma h[] de tamaño (max-min+1) y reconstruye el arreglo ordenado.

Se utiliza el desplazamiento: índice_hist = x[i] - min para mapear [min, max] a [0, max-min].

Entrada estándar
  • n (long int): número de elementos, 1 <= n <= N
  • max (int)
  • min (int)
Salida estándar
  • Arreglo desordenado
  • Arreglo ordenado
Restricciones
  • N = 300000
  • mx = 32768 (capacidad del histograma)
  • Se requiere que (max - min) <= mx - 1 para no desbordar h[].
Complejidad
  • Tiempo: O(n + (max-min))
  • Memoria: O(N + mx)
