Detailed Description

Bucket Sort (distribución por casilleros) + ordenamiento interno por selección (versión compacta).

Versión menos verbosa que Ejemplo023:

  • Genera n números aleatorios en [min, max].
  • Define nd = floor(sqrt(n)) buckets y Dx = (max-min)/nd.
  • Cuenta por bucket, calcula prefijos y distribuye a xc.
  • Ordena internamente cada bucket con Selection Sort (casos 0/1/2 optimizados).

A diferencia de Ejemplo023, aquí no se imprimen intervalos por bucket ni depuración detallada; solo muestra el arreglo final ordenado.

Entrada estándar
  • n (int): 1 <= n <= N
  • max (float)
  • min (float)
Salida estándar
  • Arreglo desordenado.
  • Arreglo ordenado.
Complejidad
Distribución: O(n) + O(nd). Ordenamiento interno: depende de la distribución; peor caso O(n^2). Memoria: O(N).
