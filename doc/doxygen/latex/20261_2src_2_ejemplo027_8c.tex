\doxysubsection{Detailed Description}
Ordenamiento por conteo (Counting Sort) para enteros en el rango \+[min, max]\+. 

Este programa genera un arreglo de {\ttfamily n} enteros aleatorios en el rango \+[min, max]\+, usa un histograma {\ttfamily h\+[]\+} de tamaño (max-\/min+1) y reconstruye el arreglo ordenado.

Se utiliza el desplazamiento:\+ índice\+\_\+hist = x\+[i]\+ -\/ min para mapear \+[min, max]\+ a \+[0, max-\/min]\+.
