\doxysubsection{Detailed Description}
Cifrado/\+descifrado XOR sobre letras (A–Z, a–z) usando una clave numérica. 

Este programa implementa un cifrado didáctico:\+
\begin{DoxyItemize}
\item Solo modifica letras del alfabeto:\+
\begin{DoxyItemize}
\item \textquotesingle{}A\textquotesingle{}..\textquotesingle{}Z\textquotesingle{} -\/\texorpdfstring{$>$}{>} valores 0..25
\item \textquotesingle{}a\textquotesingle{}..\textquotesingle{}z\textquotesingle{} -\/\texorpdfstring{$>$}{>} valores 26..51
\end{DoxyItemize}
\item A ese valor se le aplica XOR con una clave {\ttfamily cl\+\_\+c} (un byte).
\item Después se “re-\/mapea” al rango de letras:\+
\begin{DoxyItemize}
\item 0..25 -\/\texorpdfstring{$>$}{>} \textquotesingle{}A\textquotesingle{}..\textquotesingle{}Z\textquotesingle{}
\item 26..51 -\/\texorpdfstring{$>$}{>} \textquotesingle{}a\textquotesingle{}..\textquotesingle{}z\textquotesingle{}
\end{DoxyItemize}
\end{DoxyItemize}

El programa imprime trazas numéricas por carácter para mostrar la transformación.

\begin{DoxyParagraph}{Entrada estándar}
1) Una línea de texto (hasta N-\/1 caracteres) terminada con ENTER. 2) Una clave entera (se trunca a 1 byte al convertirla a char).
\end{DoxyParagraph}
\begin{DoxyParagraph}{Salida estándar}

\begin{DoxyItemize}
\item Mensaje original {\ttfamily MSG}
\item Mensaje cifrado {\ttfamily MSG E}
\item Mensaje descifrado {\ttfamily MSG D}
\item Trazas por carácter con valores intermedios.
\end{DoxyItemize}
\end{DoxyParagraph}
\begin{DoxyNote}{Note}

\begin{DoxyItemize}
\item Solo letras A–Z /\+ a–z se cifran; otros caracteres se dejan igual.
\item Es un ejemplo didáctico; no es criptografía segura.
\end{DoxyItemize}
\end{DoxyNote}
