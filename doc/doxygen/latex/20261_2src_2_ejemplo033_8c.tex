\doxysubsection{Detailed Description}
Cálculo de paridad XOR de un mensaje y simulación de error (flip) en un bit aleatorio. 

El programa lee una línea de texto (hasta N-\/1 caracteres), calcula su {\bfseries{paridad}} como:\+   \[P = m_0 \oplus m_1 \oplus \cdots \oplus m_{n-1}
\] (XOR byte a byte).

Luego simula un error de transmisión:\+
\begin{DoxyItemize}
\item selecciona un carácter aleatorio {\ttfamily nc} y un bit aleatorio {\ttfamily nb} (0..7)
\item invierte ese bit del mensaje
\end{DoxyItemize}

Después valida recalculando:\+   \[V = P \oplus m\textnormal{\textquotesingle}_0 \oplus m\textnormal{\textquotesingle}_1 \oplus \cdots \oplus m\textnormal{\textquotesingle}_{n-1}
\] Si no hubo error, típicamente {\ttfamily V==0}. Si hubo un flip, {\ttfamily V} será distinto de 0.

\begin{DoxyParagraph}{Entrada estándar}

\begin{DoxyItemize}
\item Una línea de texto (puede incluir espacios), terminada en ENTER.
\end{DoxyItemize}
\end{DoxyParagraph}
\begin{DoxyParagraph}{Salida estándar}

\begin{DoxyItemize}
\item Mensaje original, paridad P (en bits)
\item Posición y bit alterados
\item Mensaje alterado, validación V (en bits)
\end{DoxyItemize}
\end{DoxyParagraph}
\begin{DoxyParagraph}{Complejidad}
Tiempo:\+ O(n). Memoria:\+ O(\+N).
\end{DoxyParagraph}
\begin{DoxyWarning}{Warning}

\begin{DoxyItemize}
\item Se maneja el caso de mensaje vacío para evitar {\ttfamily rand()\%0}.
\end{DoxyItemize}
\end{DoxyWarning}
