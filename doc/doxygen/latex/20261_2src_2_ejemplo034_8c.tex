\doxysubsection{Detailed Description}
Inserción de paridades (Hamming) en posiciones potencia de 2 y detección de error de 1 bit. 

El programa:\+ 1) Lee un mensaje {\ttfamily msg} (hasta N-\/1 caracteres, termina al presionar ENTER). 2) Calcula {\ttfamily np} (número de paridades) con la condición mínima de Hamming:\+ 2\texorpdfstring{$^\wedge$}{\string^}np \texorpdfstring{$>$}{>}= n + np + 1 3) Construye {\ttfamily msgP} (longitud n+np) insertando bytes de paridad en posiciones 1,2,4,8,... (1-\/based). 4) Calcula las paridades por XOR usando el patrón de “bloques” del código original. 5) Simula un error:\+ invierte un bit aleatorio en un byte aleatorio. 6) Recalcula paridades y forma:\+
\begin{DoxyItemize}
\item NC\+\_\+V:\+ posición del byte con error (0-\/based)
\item NB\+\_\+V:\+ índice del bit alterado (0..7) obtenido desde la máscara XOR (potencia de 2)
\end{DoxyItemize}

\begin{DoxyParagraph}{Entrada estándar}
Una línea de texto terminada con ENTER.
\end{DoxyParagraph}
\begin{DoxyParagraph}{Salida estándar}
Mantiene la forma de impresión del programa original (MSG\+\_\+\+P/\+\+MSG\+\_\+E con s, P\+\_\+i, NC\+\_\+V, NB\+\_\+V).
\end{DoxyParagraph}
\begin{DoxyWarning}{Warning}

\begin{DoxyItemize}
\item {\ttfamily MSG\+\_\+P:\+ s} puede truncarse si dentro de {\ttfamily msgP} aparece el byte 0 (\textquotesingle{}\textbackslash{}0\textquotesingle{}). Se conserva así para no cambiar la forma de impresión original. 
\end{DoxyItemize}
\end{DoxyWarning}
