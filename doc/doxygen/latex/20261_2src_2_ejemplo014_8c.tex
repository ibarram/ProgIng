\doxysubsection{Detailed Description}
Aproximación de sen(x) con serie de Taylor calculando potencia y factorial desde cero. 

Serie de Taylor:\+ sen(x) = sum\+\_\+\{i=0\}\texorpdfstring{$^\wedge$}{\string^}\{∞\} (-\/1)\texorpdfstring{$^\wedge$}{\string^}i \texorpdfstring{$\ast$}{*} x\texorpdfstring{$^\wedge$}{\string^}\{2i+1\} /\+ (2i+1)!

Este programa aproxima con n términos:\+ sen(x) ≈ sum\+\_\+\{i=0\}\texorpdfstring{$^\wedge$}{\string^}\{n-\/1\} (-\/1)\texorpdfstring{$^\wedge$}{\string^}i \texorpdfstring{$\ast$}{*} x\texorpdfstring{$^\wedge$}{\string^}\{2i+1\} /\+ (2i+1)!

Implementación:\+
\begin{DoxyItemize}
\item Para cada i calcula num = x\texorpdfstring{$^\wedge$}{\string^}\{2i+1\} y den = (2i+1)! con un ciclo interno.
\end{DoxyItemize}
