\doxysubsection{Detailed Description}
Demostración de macros para manipulación de bits en un entero. 

El programa:\+ 1) Lee un entero {\ttfamily x}. 2) Imprime su representación binaria (desde el bit más significativo). 3) Permite aplicar operaciones sobre un bit {\ttfamily nb}:\+
\begin{DoxyItemize}
\item SET:\+ poner el bit en 1
\item CLEAR:\+ poner el bit en 0
\item TOGGLE:\+ invertir el bit
\item WRITE:\+ escribir 0 o 1 según el valor {\ttfamily v}
\end{DoxyItemize}

\begin{DoxyParagraph}{Entrada estándar}

\begin{DoxyItemize}
\item {\ttfamily x} (int)
\item {\ttfamily nb} (int):\+ índice del bit (0..(bits-\/1))
\item {\ttfamily v} (int):\+ valor 0/\+1 (solo para WRITE)
\end{DoxyItemize}
\end{DoxyParagraph}
\begin{DoxyParagraph}{Salida estándar}

\begin{DoxyItemize}
\item Representación binaria después de cada operación y el valor decimal de {\ttfamily x}.
\end{DoxyItemize}
\end{DoxyParagraph}
\begin{DoxyParagraph}{Complejidad}
Tiempo:\+ O(w) por impresión, donde w = número de bits del entero. Memoria:\+ O(1).
\end{DoxyParagraph}
\begin{DoxyWarning}{Warning}

\begin{DoxyItemize}
\item Se valida que {\ttfamily nb} esté dentro del rango permitido para evitar desplazamientos inválidos.
\end{DoxyItemize}
\end{DoxyWarning}
