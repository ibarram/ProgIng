\doxysubsection{Detailed Description}
Resta de matrices:\+ C = A -\/ B para matrices reales de tamaño n×m. 

El programa:\+ 1) Lee las dimensiones n (renglones) y m (columnas), limitadas por N y M. 2) Captura los elementos de A y B. 3) Calcula C\+[i]\+\+[j]\+ = A\+[i]\+\+[j]\+ -\/ B\+[i]\+\+[j]\+. 4) Imprime C.
