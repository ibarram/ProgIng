\doxysubsection{Detailed Description}
Ordenamiento tipo Bucket Sort (distribución por casilleros) + ordenamiento interno por selección. 

Este programa genera {\ttfamily n} números aleatorios (float) en el rango \+[min, max]\+ y los ordena usando una estrategia tipo {\bfseries{Bucket Sort}}:\+

1) Define el número de casilleros (buckets) como:\+   \[     nd = \lfloor \sqrt{n} \rfloor
\]

2) Divide el rango \+[min, max]\+ en {\ttfamily nd} intervalos de ancho:\+   \[     Dx = \frac{max - min}{nd}
\]

3) Para cada valor {\ttfamily x\+[i]\+}, calcula el casillero:\+   \[     j = \left\lfloor \frac{x[i]-min}{Dx} \right\rfloor
\] y se hace un ajuste para el caso {\ttfamily x\+[i]\+ == \doxylink{012__aleatorio_8c_a2e1da8593b0244d8e9e3b84ef7b35e73}{max}} para evitar {\ttfamily j == nd} (fuera de rango).

4) Usa un arreglo auxiliar {\ttfamily c\+[]\+} como estructura compacta:\+
\begin{DoxyItemize}
\item {\ttfamily c\+[0 .. nd-\/1]\+} :\+ conteo de elementos por casillero
\item {\ttfamily c\+[nd .. 2\texorpdfstring{$\ast$}{*}nd-\/1]\+} :\+ posiciones de escritura (inician como prefijos y luego se incrementan)
\item {\ttfamily c\+[2\texorpdfstring{$\ast$}{*}nd .. 3\texorpdfstring{$\ast$}{*}nd-\/1]\+} :\+ copia de los prefijos (inicio fijo de cada casillero en {\ttfamily xc})
\end{DoxyItemize}

5) Distribuye los datos en un arreglo {\ttfamily xc\+[]\+} agrupado por casilleros.

6) Finalmente {\bfseries{ordena cada casillero internamente}}:\+
\begin{DoxyItemize}
\item 0 o 1 elemento:\+ no hace nada
\item 2 elementos:\+ una comparación e intercambio
\item \texorpdfstring{$>$}{>}=3 elementos:\+ Selection Sort dentro del segmento del casillero
\end{DoxyItemize}

El resultado {\ttfamily xc\+[]\+} queda totalmente ordenado (ascendente) si cada casillero se ordena.
