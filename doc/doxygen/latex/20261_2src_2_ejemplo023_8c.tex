\doxysubsection{Detailed Description}
Clasificación por “casilleros” (bucket/\+distribution) de números reales en un rango \+[min, max]\+. 

Este programa genera {\ttfamily n} números aleatorios (float) dentro del rango \+[min, max]\+ y los reordena usando un enfoque tipo {\bfseries{bucket /\+ distribution sort}}:\+

1) Se elige el número de divisiones (casilleros) como:\+ nd = floor(sqrt(n))

2) Se calcula el tamaño de casillero:\+ rango = max -\/ min Dx = rango /\+ nd

3) Para cada valor x\+[i]\+ se calcula el índice del casillero:\+ j = floor( (x\+[i]\+ -\/ min) /\+ Dx )

4) Se cuenta cuántos elementos caen en cada casillero (histograma).

5) Se calcula un arreglo de posiciones iniciales (prefijos) y se construye un nuevo arreglo {\ttfamily xc\+[]\+} colocando cada elemento en su casillero correspondiente.

El arreglo {\ttfamily xc} queda {\bfseries{agrupado por intervalos}} (primero todos los del casillero 0, luego los del 1, etc.). {\bfseries{No ordena dentro de cada casillero}}, por lo que NO es un ordenamiento total, sino una etapa típica de un bucket sort (faltaría ordenar cada bucket).

\begin{DoxyWarning}{Warning}
1) El intercambio {\ttfamily min/\+max} se hace con multiplicación/\+división:\+ si alguno es 0, puede fallar (división entre 0). Para robustez usa una variable auxiliar. 2) Cuando x\+[i]\+ == max, el índice j puede resultar igual a nd (fuera del rango 0..nd-\/1). En código de producción conviene “clamp”:\+ if (j \texorpdfstring{$>$}{>}= nd) j = nd -\/ 1;
\end{DoxyWarning}
