\hypertarget{index_autotoc_md0}{}\doxysubsection{\texorpdfstring{Introducción}{Introducción}}\label{index_autotoc_md0}
Esta Unidad de Aprendizaje (UDA) desarrolla bases sólidas de programación {\bfseries{en C}} para resolver problemas de ingeniería con énfasis en:\+
\begin{DoxyItemize}
\item Estructuras de datos y algoritmos,
\item Memoria dinámica y punteros,
\item Manejo eficiente de archivos (texto y binarios),
\item Buenas prácticas de programación estructurada,
\item Trabajo profesional y ético.
\end{DoxyItemize}

\begin{quote}
Nota:\+ Este repositorio concentra materiales, código, guías y entregables de la UDA. \end{quote}
