\doxysubsection{Detailed Description}
Aproximación de π mediante la serie de Leibniz. 

Usa la serie:\+ π/\+4 = 1 -\/ 1/\+3 + 1/\+5 -\/ 1/\+7 + ...

Con n términos:\+ π ≈ 4 \texorpdfstring{$\ast$}{*} sum\+\_\+\{i=0\}\texorpdfstring{$^\wedge$}{\string^}\{n-\/1\} (-\/1)\texorpdfstring{$^\wedge$}{\string^}i /\+ (2i+1)

\begin{DoxyParagraph}{Entrada}
Un entero n \texorpdfstring{$>$}{>}= 1 (número de términos).
\end{DoxyParagraph}
\begin{DoxyParagraph}{Salida}
Imprime el valor aproximado:\+ 
\begin{DoxyCode}{0}
\DoxyCodeLine{PI\ =\ <valor>}

\end{DoxyCode}

\end{DoxyParagraph}
\begin{DoxyParagraph}{Complejidad}
Tiempo:\+ O(n). Memoria:\+ O(1).
\end{DoxyParagraph}
\begin{DoxyNote}{Note}
La convergencia es lenta:\+ para obtener muchos decimales se requieren muchos términos. 
\end{DoxyNote}
