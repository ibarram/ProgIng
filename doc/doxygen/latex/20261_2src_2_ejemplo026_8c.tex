\doxysubsection{Detailed Description}
Ordenamiento por conteo (Counting Sort) para enteros en el rango \+[0, max]\+. 

Este programa genera un arreglo de {\ttfamily n} enteros aleatorios en el rango \+[0, max]\+, construye un histograma de frecuencias {\ttfamily h\+[]\+} y reconstruye el arreglo ordenado.

Algoritmo (Counting Sort):\+ 1) Generar datos:\+ x\+[i]\+ ∈ \+[0, max]\+ 2) Inicializar histograma h\+[0..max]\+ = 0 3) Contar frecuencias:\+ h\+[x\+[i]\+]\+++ 4) Reconstruir ordenado:\+
\begin{DoxyItemize}
\item para cada valor j de 0..max, escribirlo h\+[j]\+ veces en x\+[]\+
\end{DoxyItemize}
