\doxysubsection{Detailed Description}
Genera un arreglo de enteros aleatorios y lo ordena con Odd–\+Even Sort (Brick Sort). 

El programa:\+ 1) Lee el tamaño {\ttfamily n} (1 \texorpdfstring{$<$}{<}= n \texorpdfstring{$<$}{<}= N) y un rango entero \+[min, max]\+. 2) Genera {\ttfamily n} enteros pseudoaleatorios uniformes (aprox.) en \+[min, max]\+. 3) Imprime el arreglo "{}\+Desordenado"{}. 4) Ordena el arreglo con {\bfseries{Odd–\+Even Transposition Sort}} (también llamado Brick Sort):\+
\begin{DoxyItemize}
\item En pasadas alternadas, compara e intercambia pares adyacentes:\+
\begin{DoxyItemize}
\item pasada par:\+ (0,1), (2,3), (4,5), ...
\item pasada impar:\+ (1,2), (3,4), (5,6), ...
\end{DoxyItemize}
\item Se realizan aproximadamente {\ttfamily n-\/1} pasadas. 5) Imprime el arreglo "{}\+Ordenado"{}.
\end{DoxyItemize}
