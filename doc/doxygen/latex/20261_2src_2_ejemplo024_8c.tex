\doxysubsection{Detailed Description}
Bucket Sort (distribución por casilleros) + ordenamiento interno por selección (versión compacta). 

Versión menos verbosa que Ejemplo023:\+
\begin{DoxyItemize}
\item Genera {\ttfamily n} números aleatorios en \+[min, max]\+.
\item Define {\ttfamily nd = floor(sqrt(n))} buckets y {\ttfamily Dx = (max-\/min)/\+nd}.
\item Cuenta por bucket, calcula prefijos y distribuye a {\ttfamily xc}.
\item Ordena internamente cada bucket con Selection Sort (casos 0/\+1/\+2 optimizados).
\end{DoxyItemize}

A diferencia de Ejemplo023, aquí no se imprimen intervalos por bucket ni depuración detallada; solo muestra el arreglo final ordenado.
