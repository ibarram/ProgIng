\doxysubsection{Detailed Description}
Aproximación de exp(x) con serie de Taylor (cálculo directo de potencias y factorial). 

Usa la expansión:\+ exp(x) = sum\+\_\+\{i=0\}\texorpdfstring{$^\wedge$}{\string^}\{∞\} x\texorpdfstring{$^\wedge$}{\string^}i /\+ i!

Este programa aproxima con n términos:\+ exp(x) ≈ sum\+\_\+\{i=0\}\texorpdfstring{$^\wedge$}{\string^}\{n-\/1\} x\texorpdfstring{$^\wedge$}{\string^}i /\+ i!

Para cada término i, calcula:\+
\begin{DoxyItemize}
\item num = x\texorpdfstring{$^\wedge$}{\string^}i (multiplicando x repetidamente)
\item den = i! (multiplicando 1\texorpdfstring{$\ast$}{*}2\texorpdfstring{$\ast$}{*}...\texorpdfstring{$\ast$}{*}i)
\end{DoxyItemize}
