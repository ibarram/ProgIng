\doxysubsection{Detailed Description}
Suma dos números reales recibidos por línea de comandos. 


\begin{DoxyItemize}
\item Requiere exactamente 2 argumentos numéricos:\+ argv\+[1]\+ = A argv\+[2]\+ = B
\item Convierte con {\ttfamily atof()} y calcula C = A + B.
\item Imprime con formato:\+ A(+/\+-\/)B=C
\end{DoxyItemize}
