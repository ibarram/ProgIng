\doxysubsection{Detailed Description}
Aproximación de ln(x) con serie tipo atanh calculando potencias desde cero. 

Para x \texorpdfstring{$>$}{>} 0 se usa la identidad:\+ ln(x) = 2 \texorpdfstring{$\ast$}{*} \+[ f + f\texorpdfstring{$^\wedge$}{\string^}3/\+3 + f\texorpdfstring{$^\wedge$}{\string^}5/\+5 + ... ]\+ donde:\+ f = (x -\/ 1) /\+ (x + 1)

Entonces:\+ ln(x) ≈ 2 \texorpdfstring{$\ast$}{*} sum\+\_\+\{i=0\}\texorpdfstring{$^\wedge$}{\string^}\{n-\/1\} f\texorpdfstring{$^\wedge$}{\string^}\{2i+1\} /\+ (2i+1)

Este programa:\+
\begin{DoxyItemize}
\item Lee n (número de términos) y x (valor real positivo).
\item Calcula f = (x-\/1)/\+(x+1).
\item Para cada término i calcula explícitamente f\texorpdfstring{$^\wedge$}{\string^}\{2i+1\} multiplicando f varias veces.
\end{DoxyItemize}

\begin{DoxyParagraph}{Entrada}

\begin{DoxyItemize}
\item Un entero n \texorpdfstring{$>$}{>}= 1 (número de términos).
\item Un real x \texorpdfstring{$>$}{>} 0.
\end{DoxyItemize}
\end{DoxyParagraph}
\begin{DoxyParagraph}{Salida}
Imprime la aproximación:\+ 
\begin{DoxyCode}{0}
\DoxyCodeLine{ln(x)\ =\ valor}

\end{DoxyCode}

\end{DoxyParagraph}
\begin{DoxyParagraph}{Precondiciones}

\begin{DoxyItemize}
\item x debe ser positivo (ln(x) solo está definida para x \texorpdfstring{$>$}{>} 0 en los reales).
\end{DoxyItemize}
\end{DoxyParagraph}
\begin{DoxyParagraph}{Complejidad}
Tiempo:\+ O(n\texorpdfstring{$^\wedge$}{\string^}2) (por el doble ciclo al calcular potencias). Memoria:\+ O(1).
\end{DoxyParagraph}
\begin{DoxyNote}{Note}
La convergencia es mejor cuando x está cerca de 1 (porque \texorpdfstring{$\vert$}{|}f\texorpdfstring{$\vert$}{|} es pequeño). 
\end{DoxyNote}
