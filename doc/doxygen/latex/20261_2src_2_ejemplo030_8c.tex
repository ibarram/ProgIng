\doxysubsection{Detailed Description}
Resolución de un sistema lineal Ax=b por eliminación de Gauss (sin pivoteo) y sustitución hacia atrás. 

El programa resuelve el sistema:\+ A x = b para {\ttfamily n} variables (n \texorpdfstring{$<$}{<} N) usando:\+

1) Eliminación hacia adelante (triangularización):\+ Para cada pivote i, elimina A\+[j]\+\+[i]\+ para j\texorpdfstring{$>$}{>}i:\+ fct = A\+[j]\+\+[i]\+ /\+ A\+[i]\+\+[i]\+ fila\+\_\+j = fila\+\_\+j -\/ fct \texorpdfstring{$\ast$}{*} fila\+\_\+i b\+[j]\+ = b\+[j]\+ -\/ fct \texorpdfstring{$\ast$}{*} b\+[i]\+

2) Muestra la matriz aumentada resultante \+[A\texorpdfstring{$\vert$}{|}b]\+ (ya triangular superior).

3) Sustitución hacia atrás:\+ Recorre i = n-\/1 .. 0 y calcula x\+[i]\+.

\begin{DoxyItemize}
\item {\ttfamily n} (int):\+ número de variables, 1 \texorpdfstring{$<$}{<}= n \texorpdfstring{$<$}{<} N
\item Matriz A (float):\+ n×n valores
\item Vector b (float):\+ n valores
\end{DoxyItemize}
\end{DoxyParagraph}
\begin{DoxyParagraph}{Salida estándar}

\item Solución x\+[i]\+
\end{DoxyItemize}
\end{DoxyParagraph}
\begin{DoxyParagraph}{Complejidad}

\begin{DoxyItemize}

\item Sustitución:\+ O(n\texorpdfstring{$^\wedge$}{\string^}2)
\item Memoria:\+ O(\+N\texorpdfstring{$^\wedge$}{\string^}2)
\end{DoxyItemize}
\end{DoxyParagraph}
\begin{DoxyWarning}{Warning}

\begin{DoxyItemize}
\item No hay pivoteo parcial:\+ si A\+[i]\+\+[i]\+ == 0 (o muy pequeño), puede haber división por cero o inestabilidad numérica. En implementación robusta se usa pivoteo.
\end{DoxyItemize}
\end{DoxyWarning}
