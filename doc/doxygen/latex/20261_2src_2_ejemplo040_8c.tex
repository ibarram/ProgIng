\doxysubsection{Detailed Description}
Genera n números aleatorios en \+[min,max]\+ y calcula la media. 

Uso:\+ ./\+\+Ejemplo040 n min max

Donde:\+
\begin{DoxyItemize}
\item {\ttfamily n} es el número de muestras (1 \texorpdfstring{$<$}{<}= n \texorpdfstring{$<$}{<}= N).
\item {\ttfamily \doxylink{012__aleatorio_8c_a3f06f0e9f7beb8214afeea0b18ef8377}{min}} y {\ttfamily \doxylink{012__aleatorio_8c_a2e1da8593b0244d8e9e3b84ef7b35e73}{max}} definen el intervalo; si vienen invertidos, el programa los intercambia.
\end{DoxyItemize}

El programa:\+ 1) Genera {\ttfamily n} valores:\+ x\+[i]\+ = ((max-\/min)\texorpdfstring{$\ast$}{*}rand())/\+\+RAND\+\_\+\+MAX + min 2) Imprime cada valor. 3) Calcula e imprime la media.
