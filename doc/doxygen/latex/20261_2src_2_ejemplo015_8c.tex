\doxysubsection{Detailed Description}
Aproximación de sen(x) con Taylor usando producto por término (sin factorial entero explícito). 

Serie:\+ sen(x) = sum\+\_\+\{i=0\}\texorpdfstring{$^\wedge$}{\string^}\{∞\} (-\/1)\texorpdfstring{$^\wedge$}{\string^}i \texorpdfstring{$\ast$}{*} x\texorpdfstring{$^\wedge$}{\string^}\{2i+1\} /\+ (2i+1)!

Para cada i, el término:\+ x\texorpdfstring{$^\wedge$}{\string^}\{2i+1\}/\+(2i+1)! = Π\+\_\+\{k=1\}\texorpdfstring{$^\wedge$}{\string^}\{2i+1\} (x/\+k)

Este programa calcula cada término como un producto:\+ fct = (x/\+1)\texorpdfstring{$\ast$}{*}(x/\+2)\texorpdfstring{$\ast$}{*}...\texorpdfstring{$\ast$}{*}(x/\+(2i+1)) y alterna el signo con (-\/1)\texorpdfstring{$^\wedge$}{\string^}i.
