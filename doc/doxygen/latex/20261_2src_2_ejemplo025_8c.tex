\doxysubsection{Detailed Description}
Ordenamiento alternado por selección:\+ mínimo a la izquierda, máximo a la derecha (floats). 

El programa genera {\ttfamily n} flotantes aleatorios en \+[min, max]\+ y los ordena con un método tipo {\bfseries{selección bidireccional alternada}}:\+


\begin{DoxyItemize}
\item En pasadas pares (i par):\+ selecciona el {\bfseries{mínimo}} del subarreglo actual y lo coloca al inicio (izquierda).
\item En pasadas impares (i impar):\+ selecciona el {\bfseries{máximo}} del subarreglo actual y lo coloca al final (derecha).
\end{DoxyItemize}

Los límites del subarreglo se van cerrando conforme avanza:\+
\begin{DoxyItemize}
\item izquierda = i/\+2
\item derecha = n-\/1 -\/ i/\+2
\end{DoxyItemize}

Implementación:\+
\begin{DoxyItemize}
\item Se usa una sola variable {\ttfamily i} para alternar entre mínimo y máximo (según i\%2).
\item {\ttfamily j} recorre el rango activo en dirección apropiada.
\end{DoxyItemize}
