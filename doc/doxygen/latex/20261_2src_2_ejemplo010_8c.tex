\doxysubsection{Detailed Description}
Aproximación de exp(x) con Taylor usando producto incremental dentro del término. 

Serie:\+ exp(x) = sum\+\_\+\{i=0\}\texorpdfstring{$^\wedge$}{\string^}\{∞\} x\texorpdfstring{$^\wedge$}{\string^}i /\+ i!

Este código calcula cada término i como:\+ fct = Π\+\_\+\{j=0\}\texorpdfstring{$^\wedge$}{\string^}\{i-\/1\} ( x /\+ (j+1) ) lo cual equivale exactamente a:\+ fct = x\texorpdfstring{$^\wedge$}{\string^}i /\+ i!
