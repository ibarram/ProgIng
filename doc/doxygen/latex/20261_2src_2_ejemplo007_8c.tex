\doxysubsection{Detailed Description}
Cálculo del entero i tal que 1+3+5+...+(2i-\/1) \texorpdfstring{$>$}{>}= n (relación con sqrt(n)). 

El programa usa la identidad:\+ 1 + 3 + 5 + ... + (2i-\/1) = i\texorpdfstring{$^\wedge$}{\string^}2

Restando números impares consecutivos a rn (inicialmente rn=n), el contador i se incrementa hasta que rn \texorpdfstring{$<$}{<}= 0.

Interpretación:\+
\begin{DoxyItemize}
\item Si n es un cuadrado perfecto (n = m\texorpdfstring{$^\wedge$}{\string^}2), entonces al final i = m y rn llega a 0.
\item Si n NO es cuadrado perfecto, el algoritmo termina con i = ceil(sqrt(n)).
\end{DoxyItemize}

\begin{DoxyParagraph}{Entrada}
Un entero n \texorpdfstring{$>$}{>} 0.
\end{DoxyParagraph}
\begin{DoxyParagraph}{Salida}
Imprime una línea con el formato:\+ 
\begin{DoxyCode}{0}
\DoxyCodeLine{i\string^2\ =\ n}

\end{DoxyCode}

\end{DoxyParagraph}
\begin{DoxyWarning}{Warning}
El texto impreso sugiere igualdad exacta, pero si n no es cuadrado perfecto, i\texorpdfstring{$^\wedge$}{\string^}2 != n. El valor i corresponde a ceil(sqrt(n)).
\end{DoxyWarning}
\begin{DoxyParagraph}{Complejidad}
Tiempo:\+ O(sqrt(n)). Memoria:\+ O(1). 
\end{DoxyParagraph}
