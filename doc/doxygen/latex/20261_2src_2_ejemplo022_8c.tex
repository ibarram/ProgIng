\doxysubsection{Detailed Description}
Genera un arreglo de flotantes aleatorios y lo ordena con Insertion Sort. 

El programa:\+ 1) Lee {\ttfamily n} (1..N) y un rango real \+[min, max]\+. 2) Genera {\ttfamily n} flotantes en \+[min,max]\+. 3) Imprime el arreglo "{}\+Desordenado"{}. 4) Ordena el arreglo con {\bfseries{Insertion Sort}} (orden ascendente):\+
\begin{DoxyItemize}
\item Recorre i = 1..n-\/1, toma x\+[i]\+ como {\ttfamily aux},
\item desplaza hacia la derecha todos los elementos mayores que {\ttfamily aux},
\item inserta {\ttfamily aux} en la posición correcta. 5) Imprime el arreglo "{}\+Ordenado"{}.
\end{DoxyItemize}
