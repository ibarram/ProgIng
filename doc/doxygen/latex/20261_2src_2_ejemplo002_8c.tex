\doxysubsection{Detailed Description}
Codificador de prioridad de interrupción para 4 dispositivos (D1..D4). 

Se reciben 4 solicitudes de interrupción (una por dispositivo). La prioridad se asigna de manera que el dispositivo con número más bajo tiene mayor prioridad:\+ D1 \texorpdfstring{$>$}{>} D2 \texorpdfstring{$>$}{>} D3 \texorpdfstring{$>$}{>} D4.

La salida es el número del dispositivo seleccionado codificado en binario (3 bits):\+
\begin{DoxyItemize}
\item Ninguno -\/\texorpdfstring{$>$}{>} 0 (000)
\item D1 -\/\texorpdfstring{$>$}{>} 1 (001)
\item D2 -\/\texorpdfstring{$>$}{>} 2 (010)
\item D3 -\/\texorpdfstring{$>$}{>} 3 (011)
\item D4 -\/\texorpdfstring{$>$}{>} 4 (100)
\end{DoxyItemize}
