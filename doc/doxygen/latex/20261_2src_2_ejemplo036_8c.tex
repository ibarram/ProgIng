\doxysubsection{Detailed Description}
Comparación de implementaciones de potencia, factorial y aproximación de exp(x). 

Este programa ilustra distintas formas de calcular:\+
\begin{DoxyItemize}
\item Potencia:\+ x\texorpdfstring{$^\wedge$}{\string^}n
\begin{DoxyItemize}
\item {\ttfamily \doxylink{20261_2src_2_ejemplo036_8c_a05eedb2825c7f71eb6b434aa7f369fa6}{pot()}} :\+ iterativa (for)
\item {\ttfamily \doxylink{20261_2src_2_ejemplo036_8c_a063e87787e9180491b5173ef0cfa636e}{pot2()}} :\+ recursiva
\end{DoxyItemize}
\item Factorial:\+ n!
\begin{DoxyItemize}
\item {\ttfamily \doxylink{20261_2src_2_ejemplo036_8c_a0df0cc2dd381926aef78c76ceb903fc8}{facto()}} :\+ iterativa
\end{DoxyItemize}
\item Aproximación de exp(x) con serie de Taylor (Maclaurin):\+   \[    e^x = \sum_{k=0}^{\infty}\frac{x^k}{k!}
\]
\begin{DoxyItemize}
\item {\ttfamily exp1(x,n)} :\+ suma n términos (k=0..n-\/1) usando potencia iterativa y factorial iterativo
\item {\ttfamily exp3(x,n)} :\+ suma n+1 términos (k=0..n) de forma recursiva usando {\ttfamily \doxylink{20261_2src_2_ejemplo036_8c_a063e87787e9180491b5173ef0cfa636e}{pot2()}} y {\ttfamily \doxylink{20261_2src_2_ejemplo036_8c_a0df0cc2dd381926aef78c76ceb903fc8}{facto()}}
\item {\ttfamily exp4(x,n)} :\+ suma n+1 términos (k=0..n) recursiva usando {\ttfamily \doxylink{20261_2src_2_ejemplo036_8c_ab474d57f22db312588779a8423dff075}{fct()}} que genera x\texorpdfstring{$^\wedge$}{\string^}n/\+n!
\end{DoxyItemize}
\end{DoxyItemize}
