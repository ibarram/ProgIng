\doxysubsection{Detailed Description}
Aproximación de ln(x) con serie tipo atanh usando recurrencia entre términos. 

Se usa la misma identidad que en Ejemplo012:\+ ln(x) = 2 \texorpdfstring{$\ast$}{*} sum\+\_\+\{i=0\}\texorpdfstring{$^\wedge$}{\string^}\{∞\} f\texorpdfstring{$^\wedge$}{\string^}\{2i+1\}/\+(2i+1), f = (x -\/ 1) /\+ (x + 1), x \texorpdfstring{$>$}{>} 0.

A diferencia del Ejemplo012, aquí NO se recalcula la potencia desde cero. Se usa la recurrencia de términos:\+ t\+\_\+i = f\texorpdfstring{$^\wedge$}{\string^}\{2i+1\}/\+(2i+1) t\+\_\+\{i+1\} = t\+\_\+i \texorpdfstring{$\ast$}{*} f\texorpdfstring{$^\wedge$}{\string^}2 \texorpdfstring{$\ast$}{*} (2i+1)/\+(2i+3)
