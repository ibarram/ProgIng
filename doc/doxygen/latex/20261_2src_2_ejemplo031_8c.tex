\doxysubsection{Detailed Description}
Generación de datos aleatorios y transformación por centrado/\+normalización (min–max o z-\/score). 

Este programa genera un arreglo {\ttfamily x\+[]\+} con {\ttfamily n} valores aleatorios en el rango \+[mn\+\_\+X, mx\+\_\+X]\+ y calcula estadísticas básicas:\+ mínimo, máximo, media y varianza (poblacional).

Posteriormente genera un arreglo {\ttfamily z\+[]\+} aplicando una transformación opcional:\+


\begin{DoxyItemize}
\item {\bfseries{Centrar}}:\+ restar un valor de referencia {\ttfamily a}
\item {\bfseries{Normalizar}}:\+ dividir entre un factor de escala {\ttfamily b}
\end{DoxyItemize}

De modo que:\+   \[z_i = \frac{x_i - a}{b}
\]

Métodos disponibles:\+ 1) {\bfseries{Máximo–\+Mínimo}}
\begin{DoxyItemize}
\item Centrar:\+ a = min
\item Normalizar:\+ b = (max -\/ min)
\item Con ambas opciones:\+ z = (x -\/ min)/\+(max-\/min)
\end{DoxyItemize}

2) {\bfseries{z-\/score}}
\begin{DoxyItemize}
\item Centrar:\+ a = media
\item Normalizar:\+ b = sqrt(varianza)
\item Con ambas opciones:\+ z = (x -\/ media)/\+std
\end{DoxyItemize}
