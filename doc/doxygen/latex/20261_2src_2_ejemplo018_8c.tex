\doxysubsection{Detailed Description}
Generación de un arreglo de enteros aleatorios en el rango \+[min, max]\+. 

El programa:\+ 1) Solicita al usuario el número de elementos {\ttfamily n} (1 \texorpdfstring{$<$}{<}= n \texorpdfstring{$<$}{<}= N). 2) Solicita un valor máximo y un valor mínimo. 3) Si el usuario ingresa min \texorpdfstring{$>$}{>} max, los intercambia. 4) Inicializa el generador pseudoaleatorio con {\ttfamily srand(time(\+NULL))}. 5) Genera {\ttfamily n} enteros aleatorios uniformemente distribuidos (aprox.) en el intervalo \+[min, max]\+ usando:\+ rand() \% (max -\/ min + 1) + min 6) Imprime todos los elementos generados.
