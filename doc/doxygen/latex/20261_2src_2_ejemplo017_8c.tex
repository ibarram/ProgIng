\doxysubsection{Detailed Description}
Aproximación de $\arcsin(x)$ mediante serie de Taylor (Maclaurin) para $|x|<1$. 

Este programa aproxima el seno inverso (arcoseno):\+   \[\arcsin(x)
\] usando la serie de Maclaurin (Taylor alrededor de 0), válida para $|x|<1$:\+

\[\arcsin(x) = \sum_{i=0}^{\infty}
\frac{(2i)!}{4^i (i!)^2 (2i+1)}\, x^{2i+1}, \qquad |x| < 1.
\]

En lugar de calcular factoriales grandes, la implementación construye cada término de forma incremental:\+
\begin{DoxyItemize}
\item {\ttfamily num} acumula la potencia $x^{2i+1}$ a partir de la anterior ( $\times x^2$).
\item {\ttfamily \doxylink{_ejemplo029_8c_a3b0c9965e3b03dbc43b1c6843a0bc3df}{fct}} acumula el coeficiente $C_i=\frac{(2i)!}{4^i(i!)^2}$ mediante la recurrencia:\+   \[  C_i = C_{i-1}\cdot\frac{2i-1}{2i}.
\]
\end{DoxyItemize}

Cada iteración suma:\+   \[\frac{C_i\,x^{2i+1}}{2i+1}.
\]
