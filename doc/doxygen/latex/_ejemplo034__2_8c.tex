\doxysubsection{Detailed Description}
Inserción de bytes de paridad en posiciones potencia de 2 (Hamming por bytes) y detección de un error de 1 bit. 

Este programa implementa una codificación tipo Hamming sobre un mensaje ASCII, pero trabajando a nivel de {\bfseries{bytes}} (caracteres) y usando XOR (\texorpdfstring{$^\wedge$}{\string^}) como operación de paridad.

Flujo general:\+ 1) Lee un mensaje {\ttfamily msg} hasta ENTER. 2) Calcula el número mínimo de paridades {\ttfamily np} que satisface:\+ 2\texorpdfstring{$^\wedge$}{\string^}np \texorpdfstring{$>$}{>}= n + np + 1 3) Construye {\ttfamily msgP} (mensaje extendido) de longitud L = n + np:\+
\begin{DoxyItemize}
\item en posiciones potencia de 2 (1,2,4,8,...) coloca bytes de paridad (inicialmente 0)
\item en el resto coloca los bytes del mensaje original. 4) Calcula las paridades usando el patrón de “bloques” del código original. 5) Simula un error:\+ invierte un bit aleatorio en un byte aleatorio del código. 6) Recalcula las paridades y construye:\+
\item {\ttfamily NC\+\_\+V}:\+ byte con error (0-\/based)
\item {\ttfamily NB\+\_\+V}:\+ bit con error (0..7)
\end{DoxyItemize}

\begin{DoxyParagraph}{Entrada estándar}
Una línea de texto (hasta N-\/1 caracteres) terminada con ENTER.
\end{DoxyParagraph}
\begin{DoxyParagraph}{Salida estándar}
Mantiene exactamente la forma de impresión del original:\+
\begin{DoxyItemize}
\item MSG, MSG\+\_\+P, NC/\+\+NB, MSG\+\_\+E
\item P\+\_\+i
\item NC\+\_\+V y NB\+\_\+V
\end{DoxyItemize}
\end{DoxyParagraph}
\begin{DoxyWarning}{Warning}

\begin{DoxyItemize}
\item La impresión {\ttfamily MSG\+\_\+P:\+ s} y {\ttfamily MSG\+\_\+E:\+ s} puede truncarse si aparecen bytes \textquotesingle{}\textbackslash{}0\textquotesingle{} dentro de {\ttfamily msgP}. Se conserva esta impresión por compatibilidad con el original.
\end{DoxyItemize}
\end{DoxyWarning}
