\doxysubsection{Detailed Description}
Solución de la ecuación cuadrática con raíces reales o complejas. 

Resuelve:\+ a x\texorpdfstring{$^\wedge$}{\string^}2 + b x + c = 0 usando el discriminante:\+ Δ = b\texorpdfstring{$^\wedge$}{\string^}2 -\/ 4ac

Casos:\+
\begin{DoxyItemize}
\item Δ \texorpdfstring{$>$}{>} 0:\+ dos raíces reales distintas
\item Δ = 0:\+ una raíz real doble
\item Δ \texorpdfstring{$<$}{<} 0:\+ dos raíces complejas conjugadas
\end{DoxyItemize}

Para Δ \texorpdfstring{$<$}{<} 0:\+ sqrt(Δ) = i\texorpdfstring{$\ast$}{*}sqrt(-\/Δ) y las raíces se expresan como:\+ x = (-\/b ± i\texorpdfstring{$\ast$}{*}sqrt(-\/Δ)) /\+ (2a)

\begin{DoxyParagraph}{Entrada}
Tres valores float, leídos por consola (a, b, c).
\end{DoxyParagraph}
\begin{DoxyParagraph}{Salida}
Imprime las dos raíces en forma:\+ x = real + imag\texorpdfstring{$\ast$}{*}i
\end{DoxyParagraph}
\begin{DoxyWarning}{Warning}
Si a = 0 la ecuación no es cuadrática; este programa divide entre (2a).
\end{DoxyWarning}
\begin{DoxyParagraph}{Complejidad}
Tiempo:\+ O(1). Memoria:\+ O(1). 
\end{DoxyParagraph}
