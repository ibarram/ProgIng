\doxysubsection{Detailed Description}
Multiplicación de matrices:\+ C = A \texorpdfstring{$\ast$}{*} B con verificación de dimensiones. 

El programa:\+ 1) Lee dimensiones de A:\+ n\+A×mA y de B:\+ n\+B×mB. 2) Verifica condición de multiplicación:\+ mA == nB Si no se cumple, termina con error. 3) Captura elementos de A y B. 4) Calcula C (n\+A×mB) usando:\+ C\+[i]\+\+[j]\+ = sum\+\_\+\{k=0..m\+A-\/1\} A\+[i]\+\+[k]\+ \texorpdfstring{$\ast$}{*} B\+[k]\+\+[j]\+ 5) Imprime C.
