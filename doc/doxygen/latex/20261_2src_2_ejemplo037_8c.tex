\doxysubsection{Detailed Description}
Calcula la suma de Odd\+D(k) en un intervalo \+[A,B]\+ usando recursión. 

El programa lee un entero {\ttfamily n} (número de casos) y, por cada caso, lee dos enteros {\ttfamily A} y {\ttfamily B}. Luego imprime:\+ Suma = Sodd\+D(\+A,\+B)

Donde:\+
\begin{DoxyItemize}
\item {\ttfamily Odd\+D(\+X)} devuelve el "{}componente impar"{} de X:\+ divide X entre 2 repetidamente hasta que sea impar. Ejemplo:\+ Odd\+D(12)=3, Odd\+D(40)=5, Odd\+D(8)=1.
\item {\ttfamily Sodd\+D(\+A,\+B)} suma Odd\+D(k) para k desde A hasta B (intervalo inclusivo).
\end{DoxyItemize}

Suma Odd\+D(k) para k en \+[A,B]\+ (intervalo inclusivo).
