\doxysubsection{Detailed Description}
Generación y ordenamiento de un arreglo de enteros aleatorios (orden ascendente). 

El programa:\+ 1) Solicita {\ttfamily n} (1 \texorpdfstring{$<$}{<}= n \texorpdfstring{$<$}{<}= N), y los límites {\ttfamily \doxylink{012__aleatorio_8c_a3f06f0e9f7beb8214afeea0b18ef8377}{min}} y {\ttfamily \doxylink{012__aleatorio_8c_a2e1da8593b0244d8e9e3b84ef7b35e73}{max}}. 2) Si {\ttfamily \doxylink{012__aleatorio_8c_a3f06f0e9f7beb8214afeea0b18ef8377}{min} \texorpdfstring{$>$}{>} \doxylink{012__aleatorio_8c_a2e1da8593b0244d8e9e3b84ef7b35e73}{max}}, intercambia los valores. 3) Genera un arreglo {\ttfamily x} de tamaño {\ttfamily n} con enteros aleatorios en \+[min, max]\+. 4) Muestra el arreglo “\+Desordenado”. 5) Ordena el arreglo en orden ascendente mediante un algoritmo O(n\texorpdfstring{$^\wedge$}{\string^}2) basado en comparación e intercambio (similar a selección/\+intercambio):\+
\begin{DoxyItemize}
\item Para cada i, compara x\+[i]\+ con x\+[j]\+ (j\texorpdfstring{$>$}{>}i) y si x\+[i]\+ \texorpdfstring{$>$}{>} x\+[j]\+, intercambia. 6) Muestra el arreglo “\+Ordenado”.
\end{DoxyItemize}

\item Memoria:\+ O(\+N)
\end{DoxyItemize}

\begin{DoxyNote}{Note}
Para n grande (cerca de 100000), O(n\texorpdfstring{$^\wedge$}{\string^}2) será muy lento. Este ejemplo se usa con propósitos didácticos para mostrar un ordenamiento básico.
\end{DoxyNote}
